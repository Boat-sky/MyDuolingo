# MyDuolingo — ฝึกศัพท์จีน Data Center (1,177 คำ)

## วิธีใช้
เปิดไฟล์ [index.html](index.html) ด้วยเบราว์เซอร์ (ดับเบิลคลิกได้เลย ไม่ต้องติดตั้งอะไร)
ความคืบหน้าถูกเก็บใน localStorage ของเบราว์เซอร์อัตโนมัติ

> เสียงอ่านภาษาจีนใช้ Windows TTS — ถ้าไม่มีเสียง ให้ติดตั้ง Chinese speech pack ใน
> Settings → Time & Language → Speech → Add voices → Chinese (Simplified)

## ฟีเจอร์
- **2 โหมดภาษา** 🇨🇳 จีน / 🇬🇧 อังกฤษ — สลับได้ที่หน้าหลัก ความคืบหน้า มงกุฎ และคิวคำผิดแยกกันคนละชุด
- **118 ยูนิต** ยูนิตละ 10 คำ ปลดล็อกตามลำดับ จบยูนิตได้มงกุฎ 👑
- **แบบฝึก 5 ชนิด**: คำศัพท์→ไทย, ไทย→คำศัพท์, ฟังเสียง, พิมพ์ (พินอิน/คำอังกฤษ), จับคู่
- **SRS แบบ Half-Life Regression** (ตามงานวิจัยของ Duolingo) — ปุ่ม "ฝึกทบทวน" เลือกคำที่ใกล้ลืมที่สุดมาให้อัตโนมัติ
- **ทบทวนคำที่ตอบผิด** — คำที่ผิดเข้าคิวอัตโนมัติ ตอบถูกในโหมดนี้จึงหลุดคิว
- **Gamification**: XP, สตรีครายวัน 🔥, หัวใจ 5 ดวง ❤️
- **📚 คลังคำศัพท์** — รวมคำที่เรียนแล้วทั้งสองภาษา ค้นหาได้ทุกช่อง (จีน/พินอิน/อังกฤษ/ไทย รวมถึงพิมพ์พินอินแบบไม่มีวรรณยุกต์) พร้อมแถบความแม่น 🇨🇳/🇬🇧, สถิติถูก/เห็น, วันที่ฝึกล่าสุด, ปุ่มฟังเสียง และตัวกรอง เรียนแล้ว/ใกล้ลืม/ตอบผิดค้าง/ทั้งหมด

## โครงสร้างไฟล์
- `data.js` — คำศัพท์ (generate ใหม่ด้วย `node build-data.js` เมื่อแก้ CSV)
- `engine.js` — ตรรกะ SRS + สร้างบทเรียน (ทดสอบได้ด้วย `node test-engine.js`)
- `app.js` / `index.html` / `style.css` — ส่วน UI

## เคล็ดลับจากงานวิจัย
ฝึกทุกวันวันละนิดดีกว่าอัดทีเดียวนาน ๆ — SRS ทำงานได้ดีเมื่อกลับมาซ้ำสม่ำเสมอ
และโหมด "พิมพ์พินอิน" คือการฝึก production ที่งานวิจัยชี้ว่าคนใช้ Duolingo มักขาด
